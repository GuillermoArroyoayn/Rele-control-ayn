Información para instalar

AYN todavía no conecta el equipo a la red Wi-Fi. Empareja el relé con su método compatible y luego añade el ID Tuya para comprobarlo. Solo se guarda el nombre de la red, nunca la contraseña.

Antes de habilitar un acceso, verifica el cableado y el aislamiento. Este modelo no indica contacto seco: utiliza una interfaz adecuada si el portón lo requiere. «Comprobar» consulta el estado sin encender ni apagar el equipo.
